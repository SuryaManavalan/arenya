# Sahasrajyoti ("Thousand Lights")

Working name for the Sowri line's main spirit: a vast, deity-like being of lamplight and dawn; "incomprehensibly complex… akin to a dragon, an angel or a Hindu deity" [human, form; name dm-proposed]. Hosted by Susmithaa; passes to Arenya at b1.c15. Served by Abernathy. Susmithaa's blessing: "go with all the light you can carry" [c03].
